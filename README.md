# מערכת ניהול תורים לקליניקת קוסמטיקה

מערכת ווב (Flask + SQLite) לניהול מלא של מחזור חיי תור בקליניקת קוסמטיקה: מפנייה ראשונית (ליד),
דרך קביעת תור עצמאית של הלקוח, ניהול התור על ידי המנהל/ת, ועד הפקת חשבונית וסיכומי הכנסות.
הפרויקט פותח ונבדק כאפליקציה מקומית, וכיום גם פרוס וזמין לצפייה באינטרנט.

🌐 **אתר חי:** [maorshapira.pythonanywhere.com](https://maorshapira.pythonanywhere.com/)
💻 **קוד המקור (GitHub):** [github.com/maorshapira4/Midterm-Project](https://github.com/maorshapira4/Midterm-Project)

> באתר החי, מסכי הניהול מוגנים בסיסמה (ראו סעיף "הגנת סיסמה למסכי הניהול" למטה) - זה נכון גם באתר
> החי וגם בהרצה מקומית.

## מה מומש

### ליבה (חובה)
- הוספת תור חדש (שם לקוח, שירות אחד או יותר, תאריך ושעה) - גם על ידי הלקוח וגם על ידי המנהל/ת.
- אפשר לבחור בתור אחד כמה שירותים בו-זמנית (למשל גם לק ג'ל וגם פדיקור) - המערכת מחשבת אוטומטית
  את משך הזמן הכולל ואת המחיר הכולל, כסכום כל השירותים שנבחרו.
- הצגת רשימת כל התורים, עם סינון לפי סטטוס ולפי תאריך.
- עדכון סטטוס תור (ממתין / בוצע / בוטל).
- מחיקת תור קיים.
- מניעת התנגשויות: לא ניתן לקבוע שני תורים חופפים באותו טווח זמן (נבדק לפי תאריך, שעה ומשך התור
  הכולל - כולל כשיש כמה שירותים בתור אחד).
- בעת בחירת שעה בעמוד ההזמנה, השעה שנבחרה מודגשת ויזואלית (רקע ורוד מלא), כדי שיהיה ברור ללקוח
  אילו שעה נבחרה בפועל.

### בונוס 1: ניהול לקוחות וחשבוניות מס
- טבלת לקוחות נפרדת (שם, טלפון, אימייל, כתובת).
- הוספה, צפייה ומחיקה של לקוחות.
- כל לקוח שקובע תור עצמאית באתר נכנס אוטומטית לרשימת הלקוחות: אם מספר הטלפון שהוזן כבר קיים
  במערכת, התור משויך ללקוח הקיים; אם זה טלפון חדש, נוצרת עבורו אוטומטית רשומת לקוח חדשה.
- הפקת חשבונית מס עם מספר ייחודי אוטומטי (INV-0001, INV-0002...), סכום ותאריך.
- צפייה בהיסטוריית תורים וחשבוניות לכל לקוח.

### בונוס 2: ניהול לידים
- טבלת לידים נפרדת (שם, טלפון, מקור פנייה, סטטוס, הערות).
- הוספת ליד חדש ועדכון הסטטוס שלו (חדש / בטיפול / הפך ללקוח / נדחה).
- המרת ליד ללקוח קיים במערכת (יוצרת רשומת לקוח חדשה מנתוני הליד).

### דשבורד
- מספר התורים המתוכננים השבוע הנוכחי, עם תאריכים ושעות.
- מספר התורים שהושלמו בשבוע הקודם.
- הכנסות שבועיות והכנסות חודשיות (מחושבות מתורים שסומנו כ"בוצע").

### הגנת סיסמה למסכי הניהול
כל מסכי הניהול (דשבורד, ניהול תורים, לקוחות, לידים) מוגנים בסיסמה. לקוח שמנסה להיכנס אליהם
(או שילחץ על קישור כזה) יופנה אוטומטית למסך התחברות, ולא יוכל לצפות בנתוני הניהול בלי הסיסמה.
- **הסיסמה כברירת מחדל: `1111`** (ניתן לשנות בקלות ב-`config.py`, במשתנה `ADMIN_PASSWORD`).
- לאחר התחברות מוצלחת מופיע בתפריט כפתור **"התנתקות"**, שמבטל את ההרשאה בחזרה.
- מסכי הלקוח (קביעת תור, "התורים שלי") נשארים פתוחים לכולם ללא סיסמה, כמצופה.

### הגבלה ידועה
זוהי הגנת סיסמה בסיסית מאוד (סיסמה אחת משותפת, ללא חשבונות משתמש נפרדים, וללא הצפנה) - מתאימה
להיקף פרויקט לימודי מקומי, אך לא לשימוש אמיתי מול האינטרנט. הלקוח מזהה את התורים שלו לפי מספר
טלפון בלבד (ללא סיסמה), וגם זו הפשטה מכוונת לצורך הפרויקט.

## טכנולוגיה
- **Python + Flask**: השרת רץ מקומית (`localhost`), אך בזכות ההפרדה בין הלוגיקה (Python) לתצוגה
  (תבניות HTML), ניתן בעתיד להוסיף בקלות נקודות קצה (endpoints) שמחזירות JSON כדי להזין אפליקציית
  מובייל ל-iOS/Android, בלי לשכתב את הליבה.
- **SQLite**: כל הנתונים נשמרים בקובץ `clinic.db` שנוצר אוטומטית. ניתן לצפות בו עם DB Browser for SQLite.

## מבנה הפרויקט
```

database.py                 # התחברות ל-SQLite ויצירת הטבלאות
auth.py                     # הגנת הסיסמה על מסכי הניהול (בדיקת התחברות)
schema.sql                  # הגדרת מבנה כל הטבלאות
seed_services.py            # הזנת רשימת הטיפולים הקבועה (לק ג'ל, מניקור וכו')
models/
    appointments.py         # לוגיקת תורים: הוספה (עם כמה שירותים), רשימה, סטטוס, מחיקה, התנגשויות, סלוטים פנויים
    customers.py             # לוגיקת לקוחות
    invoices.py               # לוגיקת חשבוניות
    leads.py                   # לוגיקת לידים
    reports.py                  # חישובי הדשבורד וההכנסות
routes/
    booking_routes.py       # מסכי הלקוח: הזמנה (עם כמה שירותים) וביטול
    admin_routes.py           # מסכי הניהול: תורים, לקוחות, לידים, חשבוניות
    dashboard_routes.py         # מסך הדשבורד
    auth_routes.py                # מסכי התחברות והתנתקות המנהל/ת

```
כל תכונה עסקית (תורים / לקוחות / חשבוניות / לידים / דשבורד) מקבלת קובץ Python נפרד ומשמעותי,
וכל שורת קוד כוללת הערה קצרה שמסבירה מה היא עושה.

## התקנה והרצה (macOS + VS Code)

### קיצור דרך: setup.sh
במקום לבצע ידנית את שלבים 3-5 למטה (יצירת סביבה וירטואלית והתקנת חבילות), אפשר להריץ פעם אחת
בטרמינל, מתוך תיקיית הפרויקט:
```bash
bash setup.sh
```
הסקריפט יוצר את הסביבה הווירטואלית (אם היא עוד לא קיימת), מתקין את כל החבילות הנדרשות, ובסוף
מציג בדיוק אילו שתי פקודות להריץ כדי להפעיל את האפליקציה (זהות לשלב 4 ו-6 למטה). אפשר להריץ אותו
שוב בכל שלב בבטחה - אם הסביבה כבר קיימת הוא רק ידלג על היצירה מחדש.

### שלב 1: פתיחת הפרויקט ב-VS Code
פתחו את VS Code, ואז **File → Open Folder**, ובחרו את התיקייה `פרויקטאמצע`.

### שלב 2: פתיחת טרמינל בתוך VS Code
בתפריט העליון: **Terminal → New Terminal**. ייפתח חלון טרמינל בתחתית המסך, שכבר נמצא בתיקיית הפרויקט.

### שלב 3: יצירת סביבה וירטואלית (פעם אחת בלבד)
סביבה וירטואלית היא "תיקיית עבודה" נפרדת לחבילות פייתון של הפרויקט הזה בלבד, כדי שלא יתנגשו
עם פרויקטים אחרים במחשב. הריצו בטרמינל:
```bash
python3 -m venv venv
```

### שלב 4: הפעלת הסביבה הווירטואלית
בכל פעם שפותחים טרמינל חדש לעבודה על הפרויקט, מריצים:
```bash
source venv/bin/activate
```
אם זה הצליח, אמור להופיע `(venv)` בתחילת השורה בטרמינל.

### שלב 5: התקנת החבילות הנדרשות (פעם אחת, או אחרי כל שינוי ב-requirements.txt)


### שלב 6: הרצת האפליקציה
```bash
python app.py
```
בטרמינל תופיע הודעה שהשרת רץ בכתובת `http://localhost:5000`. קובץ `clinic.db` ייווצר אוטומטית
בתיקיית הפרויקט בפעם הראשונה, עם כל הטבלאות ורשימת הטיפולים הקבועה.

### שלב 7: פתיחת האתר בדפדפן
פתחו דפדפן (Chrome/Safari) וגשו לכתובת:

תראו עמוד פתיחה עם שתי אפשרויות: **"אני לקוח/ה"** (קביעת תור/ביטול) ו-**"אני המנהל/ת"** (ניהול).

### עצירת השרת
כדי לעצור את השרת, חוזרים לטרמינל ולוחצים `Ctrl+C`.

## מדריך שימוש למי שבודק/ת את הפרויקט
לאחר שהשרת רץ (שלב 6 למעלה) ופתחתם את `http://localhost:5000` בדפדפן, תראו עמוד בית עם שתי
כניסות: **"אני לקוח/ה"** ו-**"אני המנהל/ת"**. הנה מה שכדאי לנסות בכל אחת מהן:

### כניסה כלקוח/ה (קביעת תור וביטול)
1. לחצו על **"קביעת תור"**.
2. **שלב 1**: סמנו שירות אחד או כמה שירותים מהרשימה (לק ג'ל / מניקור / פדיקור / טיפול פנים / הסרת
   שיער) - כל שירות מסומן מודגש בפינה. בחרו תאריך (לא ניתן לבחור תאריך שכבר עבר). לחצו
   **"הצג שעות פנויות"**.
3. **שלב 2**: תוצג תיבת סיכום עם רשימת השירותים שנבחרו, המשך הכולל והמחיר הכולל שלהם (סכום כל
   השירותים יחד), ומתחתיה רשימת שעות פנויות לאותו יום, מחושבת לפי המשך הכולל. לחיצה על שעה
   מדגישה אותה ברקע ורוד מלא. בחרו שעה, מלאו שם מלא, טלפון ומגדר, ולחצו **"אישור קביעת התור"**.
4. תועברו אוטומטית למסך **"התורים שלי"**, ותראו את התור שזה עתה נקבע - עם כפתור **"ביטול תור"**.
   בנוסף, מאחורי הקלעים נוצרה (או עודכנה, אם הטלפון כבר היה מוכר) רשומת לקוח במסך "לקוחות" -
   אפשר לעבור לשם ולוודא שהיא אכן מופיעה.
5. **לבדיקת ביטול**: לחצו על "ביטול תור". התור יימחק לגמרי מהמערכת (לא רק יסומן כמבוטל).
6. **לבדיקת מניעת התנגשות**: נסו לקבוע תור נוסף לאותו תאריך ושעה בדיוק (או שעה חופפת) - שימו לב
   שהיא כבר לא מופיעה ברשימת השעות הפנויות, בדיוק כדי למנוע כפל הזמנות.
7. בכל שלב אפשר לחזור למסך **"התורים שלי"** מהתפריט העליון ולהזין את מספר הטלפון שהוזן בהזמנה,
   כדי לראות שוב את התורים העתידיים שנקבעו עם אותו מספר.

### כניסה כמנהל/ת (ניהול המערכת)
1. לחצו על **"כניסת מנהל/ת"** בתפריט העליון (או על "אני המנהל/ת" בעמוד הבית), והזינו את סיסמת
   הניהול (**1111** כברירת מחדל). לאחר התחברות מוצלחת יופיעו בתפריט קישורי הניהול המלאים, וכפתור
   **"התנתקות"**.
2. **דשבורד**: מציג את מספר התורים המתוכננים השבוע (עם התאריכים והשעות), מספר התורים שהושלמו
   בשבוע הקודם, ואת סך ההכנסות השבועיות והחודשיות (מחושבות רק מתורים שסומנו כ"בוצע").
3. **ניהול תורים**: ניתן לסנן לפי סטטוס/תאריך, להוסיף תור ידנית עם שירות אחד או יותר (למשל בעקבות
   שיחת טלפון - עם אפשרות לקשר אותו ללקוח קיים או להזין אורח חדש), לשנות סטטוס תור ישירות מהרשימה
   הנפתחת שבטבלה (ממתין / בוצע / בוטל), ולמחוק תור. עמודת "שירותים" מציגה את כל השירותים שנבחרו
   לאותו תור, מופרדים בפסיקים.
4. **לקוחות**: הוספת לקוח חדש וצפייה ברשימה. לחיצה על שם לקוח פותחת עמוד פרטים עם היסטוריית
   התורים שלו, טופס להפקת חשבונית חדשה (עם מספר ייחודי אוטומטי כמו INV-0001), והיסטוריית
   החשבוניות שהופקו לו.
5. **לידים**: הוספת ליד חדש, שינוי הסטטוס שלו ישירות מהרשימה הנפתחת (חדש / בטיפול / הפך ללקוח /
   נדחה), והמרתו ללקוח רשום בלחיצת כפתור אחת ("המרה ללקוח") - פעולה שיוצרת אוטומטית רשומת לקוח
   חדשה מנתוני הליד.

### טיפ: בדיקת מחזור חיים שלם של תור בפעולה אחת
1. קבעו תור כ**לקוח/ה** (כמו למעלה), עם מספר טלפון כלשהו - המערכת תיצור עבורו לבד רשומת לקוח
   חדשה (או תשייך לרשומה קיימת, אם כבר קבעתם בעבר תור עם אותו טלפון).
2. עברו למסך **"ניהול תורים"** ועדכנו את הסטטוס של אותו תור ל**"בוצע"**.
3. עברו ל**"דשבורד"** ושימו לב שההכנסה החודשית (ולעיתים גם השבועית) התעדכנה בהתאם למחיר התור.
4. עברו למסך **"לקוחות"**, היכנסו לאותו לקוח, ותראו שהתור מופיע בהיסטוריה שלו - ומכאן אפשר גם
   להפיק לו חשבונית על הטיפול.

## צפייה בבסיס הנתונים עם DB Browser for SQLite
1. פתחו את אפליקציית DB Browser for SQLite.
2. **Open Database** ובחרו את הקובץ `clinic.db` שבתיקיית הפרויקט.
3. בלשונית **Browse Data** ניתן לבחור טבלה (customers / appointments / appointment_services /
   services / invoices / leads) ולראות את כל הנתונים שנשמרו מהאתר. הטבלה `appointment_services`
   היא טבלת קישור שמחברת כל תור לשירות אחד או יותר שנבחרו בו.

חשוב: אם השרת (`app.py`) פתוח וכותב לבסיס הנתונים בו-זמנית, ייתכן שתצטרכו ללחוץ **Write Changes**
או לרענן (**File → Refresh**) ב-DB Browser כדי לראות נתונים עדכניים.

## הרצה מחדש / איפוס הנתונים
כדי להתחיל מבסיס נתונים ריק, פשוט מוחקים את הקובץ `clinic.db` ומריצים שוב `python app.py` -
הוא ייווצר מחדש אוטומטית עם כל הטבלאות ורשימת השירותים.

## שינוי הגדרות
כל ההגדרות הניתנות לשינוי נמצאות בקובץ `config.py`: שעות פעילות הקליניקה, אורך משבצת זמן בסיסית,
ימי הפעילות בשבוע, תחילית מספרי החשבוניות, וסיסמת הניהול (`ADMIN_PASSWORD`, כברירת מחדל `1111`).
רשימת הטיפולים הקבועה (שם, משך, מחיר) נמצאת בקובץ `seed_services.py`.
